SCENARIO #01

🎪 イベントの企画から当日運営まで

秋祭り・運動会・遠足・観察会など、すべてのPTAイベントに共通する流れを、無料ツールの組み合わせで一気通貫に効率化します。

0このページで得られるもの

イベント担当に任命されたとき、「何から手をつけるか」「何をどの順で使うか」が明確になります。具体的には次の到達点を想定しています。

  • 2か月前から当日までの標準タイムラインが手元にある状態
  • 参加申込・出欠管理・連絡・当日運営をすべてクラウドで完結できる状態
  • 翌年の担当者へそのまま引き継げる資産（フォーム・スプレッドシート・連絡記録）が残る状態
ℹ️ 題材について 本ページは「秋祭り（バザー型イベント）」を題材に解説します。運動会・遠足・観察会など他のイベントでも、フォームの質問項目と当日タスクが変わるだけで、骨格は共通です。

2企画フェーズ（2か月前）

紙の企画書を回覧する文化から、クラウド共同編集に切り替えます。これだけで合意形成のスピードが2〜3倍になります。

2-2. 実行委員会のチャット拠点をLINE WORKSに作る

実行委員専用のグループトークを作成し、ピン留めメッセージに「企画書のドキュメントURL」「共有フォルダURL」「次回会議の日程」を固定します。これだけでイベント情報のハブが完成します。

個人LINEで作ってはいけない理由

個人LINEのグループは、第一にIDの相互開示が前提となるためプライバシーが混濁し、第二に役員退任後にメンバーから抜けても過去の会話履歴が他者の端末に残り続け、第三に年度末に「グループの引き継ぎ」をクリーンに行う仕組みがありません。

LINE WORKSは個人LINEと完全に別アプリとして動作するため、退任時はアカウントを削除すれば情報が手元から消去でき、組織としての情報資産管理が成立します。詳細は LINE WORKSガイド および 個人情報保護 参照。

2-3. キックオフ会議の設定

  1. 調整さんで日程候補を3〜5案提示。実行委員10名前後なら2日で確定できます。
  2. 確定したらGoogleカレンダーに予定登録。「Google Meetを追加」をオンにするとビデオ会議リンクが自動発行されます。対面とMeetのハイブリッドで参加障壁を下げてください。
  3. 会議では「議事録テンプレ」をGoogleドキュメントで開き、書記が会議中にリアルタイム入力。会議終了時点で議事録が完成している状態を作るのが目標です。

4参加申込フォーム作成（1か月前）

「聞きすぎないフォーム」が回答率を最大化します。経験則として、質問が10問を超えた時点で離脱率が急上昇します。

4-1. 質問項目の設計

秋祭りでの推奨質問項目（合計5問）。

No.質問形式必須
1保護者氏名記述式（短答）必須
2連絡先メールアドレスメールアドレス必須
3お子さんの学年ラジオボタン（1〜6年）必須
4参加人数（大人／子ども）記述式（数値）×2必須
5食物アレルギー記述式（任意）任意
質問項目を増やしたい場合の判断基準

「この情報がないと当日運営が成立しないか？」を自問してください。Yesなら追加、Noなら削除。「あったら便利」程度の項目が積み重なると、申込率が顕著に下がります。

たとえば「ボランティア協力可否」のような項目は、参加申込フォームに混ぜず、別途ボランティア募集フォームを切り分けたほうが、双方の回答率が上がります。

4-3. 配布

右上「送信」→ 🔗 リンクタブ →「URLを短縮」にチェック→コピー。LINE WORKSの保護者連絡グループに、告知文と一緒に貼り付けて配布します。

✅ 完了の判定 自分で一度フォームを送信し、メールにコピーが届くこと、運営シートに回答が自動追記されることを確認してから保護者に配布してください。テスト送信はフォーム作成時の「鉄則」です。

5告知チラシの作成（1か月前）

紙とデジタル、両方で配布します。Canvaで作れば1つのデザインを両方に流用できます。

  1. canva.com にPTA共有Gmailでログイン → 「デザインを作成」 → 「A4文書」または「チラシ」
  2. 左サイドバー「テンプレート」で「秋祭り」「学校」「イベント」を検索し、雰囲気の合うものを選択
  3. テキストをクリックして書き換え。日時・場所・主催・問合せ先を最低限表示
  4. 左サイドバー「アプリ」→「QRコード」を選び、申込フォームのURLを入力 → 紙面に貼り付け
  5. 右上「共有」→「ダウンロード」→ PDF（印刷用） でダウンロード
  6. 同じデザインをPNGでもダウンロードしておくと、LINE WORKS等のチャット配信用に使い回せる
💡 印刷の選択肢 校内のコピー機で白黒印刷が最安ですが、ラクスル・プリントパック等のネット印刷ならカラーA4両面500部で2,000〜3,000円程度（2026年時点目安）。「年に一度のイベント告知」のような限定用途では費用対効果が出ます。Canvaから直接入稿可能なサービスもあります。
QRコードの精度に関する注意

QRコードは小さくしすぎると読み取れなくなります。A4チラシなら最低でも2.5cm四方を確保してください。また、コード周囲に「余白（クワイエットゾーン）」を取らないと読み取り精度が落ちるため、QRの周囲に他の文字や図形を密着させないよう注意します。

事前に複数機種のスマホ（古い端末を含む）で読み取りテストをすることを強く推奨します。これを怠ると当日「読めません」の問い合わせが殺到します。

6申込受付・進捗管理（3週間前〜）

フォーム回答が運営シートに自動で流れ込んでいる状態を維持し、毎週1回スプレッドシートを開いて進捗を確認します。

6-1. 集計の自動化

運営シートの「申込集計」タブに以下の関数を入れておくと、回答数や学年別内訳がリアルタイムで自動更新されます。

// A1: 「現在の申込件数」
=COUNTA('フォームの回答 1'!B2:B)

// A3: 「学年別の人数」
=QUERY('フォームの回答 1'!A:E, "select C, count(C) where C is not null group by C label count(C) '人数'")

// A10: 「定員（200名）に対する充足率」
=COUNTA('フォームの回答 1'!B2:B) / 200
ℹ️ 関数が苦手な場合 上記をそのままコピー＆ペーストすれば動きます。シート名（'フォームの回答 1'）が異なる場合は実際の名前に合わせて書き換えてください。難しければ、フォームの「回答」タブにある円グラフをそのまま使えば集計は十分です。

6-2. リマインダー配信

締切1週間前と前日の2回、LINE WORKSの保護者グループでリマインドします。生成AIにリマインド文を作らせると効率的です。

小学校PTAの広報担当として、秋祭り参加申込のリマインドメッセージを作成してください。

【条件】
・配信先：保護者向けLINE WORKSグループ
・トーン：丁寧だがフレンドリー、急かしすぎない
・150〜200字
・申込フォームのURLを末尾に置く前提（URLは自分で挿入する想定）
・現在の申込状況に触れる：「すでに約180名の方からお申込みいただいています」

短い案を3つ出してください。

7直前準備（1週間前）

7-1. 当日進行表の完成

進行表（タイムテーブル）をGoogleドキュメントで作成し、PDFに書き出して、印刷したものを当日各ブースに配布します。同時にPDFを共有フォルダに置き、実行委員のスマホからすぐ参照できるようにします。

7-2. 緊急連絡ツリー

運営シートの「緊急連絡」タブに、以下を整理しておきます。当日のスマホ1台で見られる状態にすることが重要です。

  • 会長・副会長・会計の電話番号
  • 学校警備員室の内線
  • 近隣の救急対応病院（休日診療含む）
  • 消防・警察の最寄り連絡先
  • 当日キャンセル時の代替連絡網（業者・備品レンタル）

7-3. 直前リマインドと持ち物確認

前日夕方にLINE WORKSで全員に最終リマインド。持ち物・集合時間・雨天時の判断基準（朝7時の段階で◯◯なら順延）を明文化します。

⚠️ 雨天判断の責任所在 「誰が」「いつまでに」「どの判断基準で」雨天延期を決めるかを事前に文書化してください。当日の朝に電話で議論する状態は最悪です。たとえば「会長が、当日朝6:30の気象庁発表降水確率を見て、70%以上なら延期、即時LINE WORKSとメールで一斉連絡」のように具体化します。

8当日運営

紙とデジタルのバランスを取ります。当日はスマホの電池とネットワークが落ちる可能性を想定し、紙のバックアップを必ず用意します。

8-1. 受付の運用

受付では、印刷した参加者一覧（申込スプレッドシートをPDF出力）でチェック。スマホでも同じスプレッドシートを開いておき、当日申込者の追記はデジタル側で対応します。

8-2. トラブル発生時のフロー

  1. 第一発見者が無線または近くの実行委員に口頭で報告
  2. 同時にLINE WORKSの実行班グループに状況を投稿（後で時系列を追えるようにする）
  3. 会長または副会長が判断 → 必要なら救護担当・学校・外部機関へ連絡
  4. 解決後、運営シートの「インシデント記録」タブに発生時刻・対応・所要時間を記録
💡 写真撮影の同意確認 当日の受付で、肖像権同意の有無を申込時情報と突合できるよう、参加者バッジに色分け（同意=青、未確認=黄）するなどの工夫が有効です。撮影担当はバッジ色を見て撮るかどうか判断します。

9振り返り（翌週）

9-1. 写真の整理と共有

実行委員が撮影した写真をGoogleドライブの「05_当日写真」に集約。肖像権同意済みの児童のみが映る写真を選別し、「05_当日写真_公開可」フォルダにコピーします。このフォルダのリンクを保護者に共有することで、ダウンロード可能なフォトアルバムとして機能します。

9-2. お礼のお便り作成

生成AIで下書きを作成 → ドキュメントで共同編集 → CanvaでデザインしてPDF配布、という流れが最速です。詳細は お便り作成ガイド 参照。

小学校PTAの広報担当として、秋祭り終了後の保護者向けお礼のお便りを作成してください。

【条件】
・トーン：あたたかく、感謝が伝わる
・400〜500字
・盛り込む要素：
  - 当日の参加者数（約380名）
  - ボランティア協力者への感謝
  - 印象に残った場面（具体的なエピソードは仮で可、後で差し替える前提）
  - 来年度への意気込み
・最後に写真フォルダのリンクを案内する一文を入れる

9-3. 振り返り会議と引き継ぎノート

イベント後2週間以内に振り返り会議をMeetで開催。「うまくいったこと／改善点／来年への申し送り」の3カテゴリで議事録を作り、Notionまたは Googleドキュメントの「引き継ぎノート」に追記します。

✅ 翌年への資産化 「秋祭り」フォルダ全体を「99_過去年度参考資料」配下にコピーして保管。来年の担当者は、このフォルダをコピーして上書き編集すればゼロから企画書を書く必要がありません。これがクラウド運用の最大の利点です。詳しくは 年度引き継ぎ設計 を参照してください。
